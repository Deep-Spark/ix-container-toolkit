# IluvatarCorex Container Toolkit Changelog
## v1.1.0

- [ix-container-runtime] Mount `/dev/itrctl` for driver 4.4.0 compatibility.
- [ix-container-runtime] Added support for CoreX SDK mounting and its configuration toggle.
- [ix-container-runtime] Added support for the containerd v2 configuration format.


## v1.0.0

- [ix-ctk] Support configure docker, containerd and cri-o runtime
- [ix-ctk] Support generate CDI
- [ix-container-runtime] Support mount GPU devices using `IX_VISIBLE_DEVICES` environment variable
